# Audit Service

## Overview

The Audit Service is responsible for collecting, storing, and managing immutable audit events generated across the AEV Platform. It ensures traceability, compliance, accountability, and security monitoring by maintaining an append-only audit trail.

This Week 1 implementation focuses only on project setup and infrastructure preparation. Event processing and business logic will be implemented in later milestones.

# Objectives

The Audit Service provides a secure foundation for recording system events generated by all platform services.

Primary goals include:

- Immutable audit logging
- Security monitoring
- Compliance support
- Traceability
- Event search
- Hash-chain verification
- Long-term log retention

---

# Service Responsibilities

- Receive audit events from Kafka
- Validate incoming events
- Store immutable audit logs
- Maintain cryptographic hash chain
- Support audit search
- Support audit verification
- Provide compliance records

# Environment Variables

| Variable | Description |
|----------|-------------|
| PORT | Port on which the Audit Service runs |
| DB_HOST | PostgreSQL database host |
| DB_PORT | PostgreSQL database port |
| DB_NAME | Audit database name |
| KAFKA_BROKER | Kafka broker address |
| KAFKA_TOPIC | Kafka topic for audit events |

Example:

```env
PORT=8081

DB_HOST=postgres
DB_PORT=5432
DB_NAME=audit

KAFKA_BROKER=kafka:9092
KAFKA_TOPIC=audit-events
```

# Docker

Dockerfile included for containerized deployment.

Build:

```bash
docker build -t audit-service .
```

Run:

```bash
docker run -p 8081:8081 audit-service
```

The Audit Service will be available at:

```
http://localhost:8081
```
